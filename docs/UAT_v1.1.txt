===== SHEET: How to use (8x1) =====
Ecofy Lead Workspace — UAT scenarios v1.1
Run in the sandbox (ecofy-sandbox.itarang.com) with the seed applied and one standard system per type entered.
P0 scenarios must all pass before go-live. P1 failures need a dated fix plan agreed by both founders.
Each scenario is run by the role shown. Record Pass / Fail / Blocked, the tester, the date, and a screenshot reference in Notes for any failure.
Refs point to BRD requirements, Build Baseline answer ids (S0.1 …), earned rules, and database checks (T01 …) in the schema test file.
